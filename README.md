# PlanBee Vision

Build a **premium, cinematic, high-end website for PLANBEE** using the uploaded **PlanBee Company Profile PDF as the single source of truth for all company content**.

The website should look like a **premium experiential events, entertainment and marketing agency**, not a generic corporate website or SaaS landing page.

The most important sections I want you to build exceptionally well are:

1. Hero
2. About PlanBee
3. What We Do / Expertise
4. Services
5. **Trusted Partnerships / Our Clients**
6. **Past Work / Events**
7. Why PlanBee
8. Contact

Do not invent any company information, clients, case studies, statistics or services that are not present in the PDF.

---

# DESIGN DIRECTION

Create a sophisticated **luxury editorial + cinematic event-agency aesthetic**.

Visual references:

* Premium event production agency
* Luxury fashion editorial
* Music festival website
* High-end creative agency
* Entertainment production company
* Premium hospitality brand

### Color direction

Primary:

* Deep black
* Charcoal
* Off-white
* Warm neutral tones

Accent:

* Very subtle champagne/gold

Avoid making the website overly gold.

### Typography

Use a premium combination such as:

* Elegant serif display font for major headlines
* Modern clean sans-serif for body/UI

Use oversized typography strategically.

The site should have:

* Large editorial headlines
* Huge numbers
* Strong whitespace
* Thin borders
* Asymmetric layouts
* Full-width imagery
* Cinematic photography
* Subtle grain/noise where appropriate

Avoid:

* Generic card grids
* Excessive rounded corners
* Excessive gradients
* Cheap-looking animations
* SaaS-style dashboards
* Too many UI cards
* Overly colorful design
